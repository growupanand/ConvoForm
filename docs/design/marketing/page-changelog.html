v0.19.0

AI response insights, file uploads and Docker self-hosting

Feature×9Improvement×6Fix×5
  • AI-powered insights for each response: a TL;DR, tone, sentiment and the respondent’s queries.
  • More AI providers: Groq and Ollama.
  • File upload field, so respondents can attach documents and images.
  • Respondent metadata (device, browser, location) and automatic emails when a form is finished.
  • Docker Compose support for self-hosting, plus a refreshed sidebar.

Fixes: file upload “user not found”, MCQ label overflow, invalid CSV values, missing conversation names, React Server Components CVEs.

v0.18.0

Google Forms import and new answer inputs

Feature×10Improvement×1Fix×2
  • Import a Google Form from Drive: text, date, multiple choice and scale/rating questions.
  • New Rating input, and multi-select for multiple choice.
  • Date input understands natural language (“next Friday”) and has a time picker.
