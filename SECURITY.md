# Security Policy

## Supported versions

Security fixes are applied on the latest released version of ConvoForm (`0.19.x` and current `main`). Older releases are not patched.

## Reporting a vulnerability

**Do not** open a public GitHub issue for a security report.

Please report vulnerabilities in one of these ways:

1. **Email** [contact@convoform.com](mailto:contact@convoform.com) with a description of the issue, steps to reproduce, and impact if known.
2. **GitHub private advisory** at [Report a vulnerability](https://github.com/growupanand/ConvoForm/security/advisories/new).

You should receive an acknowledgment when the report is seen. We will follow up with next steps, including whether we accept the report and when a fix is planned. Please keep the details private until we publish a fix or confirm the report is not a vulnerability.

For questions that are not security issues, use [GitHub Issues](https://github.com/growupanand/ConvoForm/issues/new/choose) or [Discord](https://discord.gg/aeYtKyn2E2).
